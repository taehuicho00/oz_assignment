콘솔 계산기

이 페이지의 계산기는 화면이 아니라 브라우저의 Console(콘솔)에서 동작합니다. 곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산하고, 긴 계산식도 계산할 수 있습니다.

1. 콘솔 열기

  • Windows: F12 또는 Ctrl + Shift + J
  • macOS: Option + Command + J (Chrome 기준)

열린 창에서 Console 탭을 선택합니다.

2. 한 번에 계산하기: calc("식")

> calc("1 + 2 * 3")
1 + 2 * 3 = 7
> calc("10 - 4 / 2 * 3 + 1")
10 - 4 / 2 * 3 + 1 = 5
> calc("0.1 + 0.2")
0.1 + 0.2 = 0.3
> calc("7 / 0")
계산할 수 없습니다: 0으로 나눌 수 없습니다.

3. 입력창으로 계속 계산하기: start()

> start()

입력창이 뜨면 계산식을 입력하고 확인을 누르세요. 결과가 콘솔에 출력되고 입력창이 다시 뜹니다. 취소를 누르면 끝납니다.

입력 규칙

  • 숫자와 + - * /만 쓸 수 있습니다. 공백은 있어도 없어도 됩니다. (1+2*3도 가능)
  • 음수와 소수도 됩니다. 예) -3 + 2.5 * 4, 2 * -5
  • 0으로 나누기, 연산자로 끝나는 식(5 +), 연산자가 잘못 이어진 식(1 + * 2)은 계산하지 않고 이유를 알려 줍니다.

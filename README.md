## JavaScript 1일차: 콘솔 예상 출력

```
> calc("1 + 2 * 3")
1 + 2 * 3 = 7
> calc("10 - 4 / 2 * 3 + 1")
10 - 4 / 2 * 3 + 1 = 5
> calc("2 * 3 + 4 * 5 - 6 / 2")
2 * 3 + 4 * 5 - 6 / 2 = 23
> calc("100 / 4 / 5 + 3 * 3 - 1")
100 / 4 / 5 + 3 * 3 - 1 = 13
> calc("0.1 + 0.2")
0.1 + 0.2 = 0.3
> calc("-3 + 2.5 * 4")
-3 + 2.5 * 4 = 7
> calc("7 / 0")
계산할 수 없습니다: 0으로 나눌 수 없습니다.
> calc("1 + * 2")
계산할 수 없습니다: 연산자가 연달아 나왔거나, 숫자가 와야 할 자리에 연산자가 있습니다.
> calc("5 +")
계산할 수 없습니다: 계산식이 연산자로 끝났습니다.
```

계산 로직만 Node.js로 확인할 수도 있습니다. (저장소 최상위 폴더에서)
```bash
node -e 'const c = require("./JS/day1/calculator.js"); console.log(c.calculate("10 - 4 / 2 * 3 + 1"))'
# 출력: 5
```
